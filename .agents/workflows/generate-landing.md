# Workflow: /generate-landing

Este workflow activa a toda la orquesta de agentes para construir la landing page de Luxxor de inicio a fin.

**Pasos de ejecución:**

1. **Lead Agent - Planificación**
   - Analiza los folletos adjuntos y requerimientos.
   - Crea el Master Plan del proyecto en la raíz del workspace.
   - Solicita revisión y aprobación del usuario.

2. **UX/UI Designer Agent - Diseño Visual**
   - Establece la paleta de colores (Dorado, Negro, Blanco).
   - Define tipografías elegantes y el estilo "premium minimalista".
   - Genera sugerencias o placeholders para el logo LX dorado-negro y fotos de interiores lujosos.

3. **Frontend Developer Agent - Implementación**
   - Inicia un proyecto web con las tecnologías permitidas (ej. npm, frameworks recomendados por el Lead Agent).
   - Construye la interfaz respetando rigurosamente los lineamientos del UX/UI Designer.

4. **SEO & Conversion Agent - Optimización**
   - Configura meta etiquetas y palabras clave orientadas a SEO local (Cali).
   - Implementa y destaca los botones "Call to Action" conectados a WhatsApp.

5. **QA & Performance Agent - Revisión Final**
   - Ejecuta auditoría simulada o real de Lighthouse (Performance, Accessibility, Best Practices, SEO).
   - Asegura la perfecta visualización y rendimiento en modo Mobile-First.

6. **Despliegue**
   - Comprueba conexión con GitHub y Vercel (mediante MCP).
   - Prepara el despliegue automático.
