# Tailwind Premium

Always use these practices:
- Custom luxury palette (`#D4AF37` gold, `#121212` black).
- Use `backdrop-blur`, `bg-opacity`, and subtle `shadow-xl` for depth.
- Minimalist spacing (`py-24`, `gap-16`) to let content breathe.
- Smooth transitions: `transition-all duration-500 ease-in-out`.
