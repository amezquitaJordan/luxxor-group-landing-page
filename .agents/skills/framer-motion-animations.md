# Framer Motion Animations

- Use `initial={{ opacity: 0, y: 20 }}`, `whileInView={{ opacity: 1, y: 0 }}` for scroll reveals.
- Staggered children for lists/grids.
- Keep animations smooth and slow (0.6s to 1s duration) for a premium feel.
- Only animate elements when they are deeply visible (`viewport={{ once: true, margin: "-100px" }}`).
