# Luxxor Landing Page Global Rules

## Settings
- **Planning Mode**: ON
- **Review Policy**: Request Review
- **Terminal Execution Policy**: OFF (Allow List: npm, git, vercel)
- **MCP Connections**: Vercel, GitHub (connected for automatic deployment)

## Agents Roles (Orchestra)
1. **Lead Agent**: Coordinador principal. Crea el plan maestro, gestiona la comunicación entre roles y aprueba todos los cambios.
2. **UX/UI Designer Agent**: Especialista visual. Encargado de replicar el estilo de los folletos: logo LX dorado-negro, estética premium minimalista, fotos de interiores lujosos, tipografía elegante y paleta dorado-negro-blanco.
3. **Frontend Developer Agent**: Implementador técnico. Transforma el diseño en la landing page funcional usando código limpio y moderno.
4. **SEO & Conversion Agent**: Especialista en marketing. Optimiza el contenido para SEO local en Cali e implementa el embudo de conversión vía WhatsApp.
5. **QA & Performance Agent**: Revisor de calidad. Realiza auditorías de Lighthouse, valida la accesibilidad y verifica que la experiencia sea 100% mobile-first.

## Modo de Trabajo
- Uso de **progressive disclosure** de skills a medida que avanza el proyecto.
- Ejecutar confirmaciones (Request Review) antes de avances significativos.
